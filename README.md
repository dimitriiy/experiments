# Experiments

This repository contains various experiments organized into separate projects.

## Projects

- **frontend/** - Shadcn/UI Landing Page Template
  - React + TypeScript + Tailwind CSS
  - Fully responsive landing page with dark mode
  - Includes sections: Navbar, Hero, About, Features, Pricing, FAQ, and more
  - To run: `npm install && npm run dev`

## Experiments List

List of JavaScript/React "bicycles" - reimplementations of popular libraries for educational purposes:

1. **react-query** - Implement suspense react query
2. **my-di** - Dependency Injection
3. **my-router** - Simple routing library for web applications
4. **atom** - Atomic state management (Reatom/Recoil clone)
5. **long-tasks** - Processing long tasks without blocking UI
6. **Signals** - Reactive signals (Preact Signals clone)
7. **SWRApp** - Data fetching and caching (SWR clone)
8. **own-effector** - Event-driven state management (Effector clone)
9. **own-zustand** - Minimalist state management (Zustand clone)
10. **own-vue** - Reactive interfaces (Vue.js clone)
11. **own-mobx** - Observable state management (MobX clone)
12. **typing-effect** - Typewriter effect
13. **transition** - Smooth transitions and animations
